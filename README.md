# 🚚 Supply Chain & Logistics Analytics

## 📌 Project Overview
This project analyzes supply chain delivery performance, order shipping statuses, and category-level product sales using Python and Pandas to identify late delivery risks and optimize logistics workflow.



## 📁 Datasets Used
1. **`DataCoSupplyChainDataset.csv`**: Raw supply chain transaction data containing delivery statuses, order quantities, and sales metrics.
2. **`exported_supply_chain_analysis.csv`**: Processed and aggregated summary dataset generated using Python Pandas for category-wise order metrics.



## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Environment:** Jupyter Notebook / VS Code



## 📊 Key Insights & Features
- Analyzed shipping modes and late delivery risk distribution.
- Grouped category-level demand with delivery performance.
- Generated automated summary metrics for reporting.
